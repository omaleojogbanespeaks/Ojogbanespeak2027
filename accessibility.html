Accessibility

Our commitment to making this website clear, usable and accessible to as many visitors as possible.

Our Accessibility Commitment

This website is designed to provide information about Victor Omale Ojogbane and the development priorities presented on this platform in a clear and accessible format.

We aim to make the website usable across different devices, including mobile phones, tablets and desktop computers.

Website Accessibility Features

The website includes features intended to make navigation and information access easier.

  • Responsive design for mobile phones, tablets and computers.
  • Clear navigation menus across the website.
  • Readable typography and appropriate spacing.
  • Descriptive headings and structured content.
  • Text-based information alongside visual content where appropriate.
  • Keyboard-friendly links and interactive elements where possible.
  • Clear contrast between text and background areas.

Images and Alternative Text

Images used throughout the website are intended to support the information presented on each page.

Where appropriate, images include alternative text to help visitors who use screen-reading technology understand the purpose or subject of an image.

Navigation

The website uses a consistent navigation structure to help visitors move between the main sections of the site.

Important information can also be accessed through the Resources, Search, Sitemap and Contact pages.

Using the Website on Mobile Devices

The website has been designed to adapt to smaller screens. On mobile devices, the main navigation can be opened using the menu button at the top of the page.

Visitors can use normal touch gestures such as scrolling, tapping links and opening navigation menus.

Feedback and Accessibility Issues

If you experience difficulty accessing information or using any part of this website, please contact us so the issue can be reviewed.

When reporting an accessibility issue, it is helpful to include the page where the problem occurred and a short description of what happened.

Continuous Improvement
